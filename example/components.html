MY UI / HTML + CLASS

纯 HTML 组件示例

只引入一份 CSS，用标签和 class 组合组件。输入、勾选、单选和表单重置都由浏览器原生完成。

按钮 Button

主按钮、描边、文字和禁用状态；按下反馈由 CSS 提供。

查看 HTML 
<button class="my-button my-primary" type="button">保存</button>
<button class="my-button my-outline" type="button">取消</button>
<button class="my-button my-primary" type="button" disabled>不可操作</button>

标签 Tag

用颜色类名表达不同的内容状态。

默认 已完成 处理中 需关注 已归档
查看 HTML 
<span class="my-tag my-green">
  <span class="my-tag-content">已完成</span>
</span>
